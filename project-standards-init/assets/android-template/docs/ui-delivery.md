## 设备验收步骤

针对目标项目裁剪，每次写实际设备/API、操作、预期和结果：

1. 在目标手机尺寸启动主要任务，检查系统栏、内容边距、触摸目标和文本缩放。
2. 在实际支持的平板、折叠设备或横屏尺寸重复操作，检查导航、内容列与返回行为。
3. 按产品实际支持范围检查浅色/深色、动态颜色回退、RTL 与本地化长文本。
4. 用 TalkBack 完成主要任务；逐个检查名称、角色、状态、焦点顺序和恢复反馈。
5. 展示键盘、执行表单或搜索操作、隐藏键盘并返回；检查焦点、IME action 和可见提交操作。
6. 执行系统返回手势并观察 predictive back 预览。确认根 Activity 未拦截系统行为，页面状态按目标导航方案恢复。
7. 有实验 Expressive API 或自定义动效时，在实际解析版本和减少动态效果设置下重复操作，确认动画结束、取消与状态反馈。

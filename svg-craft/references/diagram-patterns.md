# SVG 图表与版式模式库（Diagram Patterns）

画图前先对号入座选一种模式，按对应网格规则计算坐标，不要临场自由发挥。

---

## 模式 1 · 分层系统架构图（Architecture Diagram）

- **推荐画布**：`viewBox="0 0 1280 720"`（16:9）
- **外边距**：`48px`；顶部标题区占 `y: 36..108`；主体绘图区 `y: 128..640`；右下角图例区 `y: 652..696`。
- **网格布局**：
  - 按数据流方向采用 **左 → 右（3–4 列 Region）** 或 **上 → 下（3–4 层 Region）**。
  - 每个 Region 用带浅色虚线框的 `<rect rx="14" stroke-dasharray="6 4"/>` 包裹，左上角放胶囊形 Region Label（高度 `24px`，左右各留 `10px` padding）。
  - 节点统一圆角 `rx="10"`，标准尺寸 `160–210px × 60–72px`，同列节点左对齐且垂直间距统一（`20–28px`）。
- **走线规则**：
  - 同层或相邻层水平直连，跨列绕行时在 Region 间隙的“走线通道（宽 `40–60px`）”里折弯。
  - 同步调用用实线 + `url(#arrow-muted)`；异步事件用虚线 `stroke-dasharray="5 4"` + `url(#arrow-hollow)`；主高亮链路用 `2.25px` 强调色 + `url(#arrow-accent)`。

## 模式 2 · 底层内存布局 / 数据结构 / 指针链图（Memory & Struct Layout）

> 适用于：C/C++/Rust/VM 结构体内存对齐、哈希表与混合容器、调用栈帧、指针链、分页映射与垃圾回收（GC）状态图。

- **推荐画布**：`viewBox="0 0 1280 720"`（演示/宽图）或 `960 560`（笔记紧凑图），优先使用**主题 A（深色工程科技）**。
- **结构体块画法（Memory Block）**：
  - 宽 `280–380px`，顶栏高 `40–48px`（显示结构体名如 `struct HybridMap` + 左侧图标 + 右侧字节大小徽章，确保字节偏移与总大小数学一致）。
  - 内部字段逐行堆叠，每行高 `36–44px`，用 `1px` 低对比横线分隔：
    - 左列（定宽 `56px`）：偏移量 `+0x00`、`+0x10`（等宽 `11–12.5px` 灰色）
    - 中列：字段类型 + 名称（如 `Value *array`）
    - 右列：值 / 状态标签（如 `4 / 2` 或实心小圆点锚点）
- **数组 / 连续内存条画法（Contiguous Array / Stack）**：
  - 横向或纵向连续单元格，每个槽位固定宽高（如 `136×72px` 或 `72×52px`），外侧标索引 `[0] [1] [2]` 或递增地址。
  - 空槽位用虚线/低透明度表示，活跃槽位用语义色高亮，栈顶/游标用侧边带箭头胶囊指针精确指向槽位中线。
- **指针连线规范**：
  - 指针字段右侧放实心圆点锚点（`r="4"`），从圆点出发用正交圆角折线或平滑三次贝塞尔（`C`）精确贴合目标结构体边框。
  - 若存在回指或冲突链（如 `next` 偏移链），统一从下方通道绕行，避免穿过内部文字；同时把指针放在 `layer-overlay-edges`（节点层之上）避免被容器底色遮挡。

## 模式 3 · 机制 / 因果链路 / 管线图（Mechanism & Pipeline）

> 适用于：算法步骤、编译器管线、状态机流转、RAG / Agent 执行链路、请求生命周期。

- **推荐画布**：`1280×720`（横向 3–5 阶段）或 `1200×640`。
- **节奏结构**：
  - 阶段编号胶囊 `01` / `02` / `03` 放在每个主卡片左上角，一眼看清阅读顺序。
  - 阶段卡片等宽（例如 4 阶段：每个宽 `248px`，间距 `48px`，总宽 `1136px`，左右各留 `72px`）。
  - 卡片内部遵循 **「图标 + 标题 → 1 个微型示意图或关键代码片段 → 1–2 行极简说明」**，拒绝纯文字塞满框。
  - 若有反馈回路或条件分支（如缓存命中 vs 未命中、屏障触发），主干放水平中轴，分支放上方或下方次轴并用语义色区分。

## 模式 4 · Bento 便当格信息卡片（Bento Grid Infographic）

> 适用于：一图总结、核心指标概览、知识点小抄、视频封面或章节总览卡。

- **推荐画布**：横版 `1280×720`（4 列 × 2 行基础网格）或竖版 `800×1000`（2 列 × 4 行基础网格）。
- **首选主题**：**主题 B（暖纸编辑风）** 或 **主题 A（深色极简风）**。
- **排布铁律**：
  - 必须**非对称**：1 个大号 Hero 模块（占 `2×2` 或 `2×1` 格，放核心视觉锚点 / 超大数字 / 主简图）+ 4–6 个中小模块（`1×1` / `1×2`）。
  - 所有模块共用同一圆角（`rx="20"` 或 `24`）和同一间距（`gap = 16px`），外边缘严格齐平。
  - 至少有 **2 个模块包含非纯文本视觉元素**（超大 KPI 数字、微型柱状/折线图、进度条、图标矩阵或对比徽章）。
  - 全图只允许 1 个模块使用高饱和强调色底（或只用强调色标 2 处核心数字）。

## 模式 5 · 二元对比 / 演进对比图（Before vs After / A vs B）

> 适用于：版本演进对比、架构重构前后、优化前 vs 优化后、常见误区 vs 正解。

- **推荐画布**：`1280×720`。
- **布局**：
  - 左右对称双大卡片（各宽 `548px`，中间留 `88px` 通道放 `VS` 或向右演化箭头 `→`），外边距 `48px`。
  - 左卡用中性灰蓝或柔和警示色（Rose/Amber），右卡用正向核心色（Emerald/Cyan/Blue）。
  - 两条对比项在**同一水平基线（相同 `y` 坐标）**上逐行对齐，便于横向扫读差异。
  - 底部加一条贯通全宽的「核心结论条（Key Takeaway Banner）」，总结最值得记住的一句话。

## 复杂版式打样与矢量化边界

- **先概念打样，后原生重写**：若构图很新且难以一次敲定重心，可先用宿主图像工具或项目级生图技能生成 1–2 张构图参考图，确认重心与留白后，再严格按 `svg-craft` 网格与 `<defs>` 重写为原生 SVG。
- **严禁将文字/架构位图直接矢量化**：对含文字、表格、细网格或渐变阴影的 PNG 做自动矢量化，会产生数千个不可编辑的破碎路径点，彻底丧失 SVG 清晰轻量的优势。仅极简 2–3 色无文字扁平图标/剪影允许矢量化并经 SVGO 精简后作为装饰嵌入。

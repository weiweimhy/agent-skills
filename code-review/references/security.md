# Security High-Risk Review Checks

只在改动涉及认证鉴权、外部输入、文件/URL/命令边界、密钥配置或依赖供应链时按需核对，不替代专业渗透测试：

- **资源级授权**：确认鉴权与具体资源和动作绑定，不把“已登录”当“有权限”，不信任客户端传入的角色、租户、用户 ID 或路径决定服务器端访问。
- **不可信输入与危险汇点**：检查外部请求、回调、消息队列、文件与环境变量是否经过校验与规范化；核对参数化查询、受控文件路径（防遍历）、命令执行及 URL/主机 allowlist（防 SSRF）。
- **密钥与敏感信息边界**：确认凭据只来自受管配置，未硬编码进代码、测试夹具、镜像、日志或错误响应；错误信息不得泄露内部堆栈或安全判断细节。
- **Web 与会话边界**：按项目客户端与部署模型核对编码、CORS、cookie 属性、速率限制与共享缓存隔离（带认证或个性化响应不得误入共享缓存）。
- **供应链与外部副作用**：检查依赖/锁文件/构建脚本改动是否具备正当来源与兼容性测试；轮换或撤销凭据、执行扫描或利用验证属于外部操作，须先取得明确授权。
